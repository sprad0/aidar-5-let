# Айдар — 5 лет · сайт-приглашение

Одностраничный сайт-приглашение на день рождения в супергеройском стиле.
Сначала показывается конверт, по клику он открывается, взлетают шарики и
появляется приглашение. Дальше — именинник, календарь и обратный отсчёт,
программа, место на карте 2ГИС, галерея «Моменты», вишлист, детали и анкета
гостя, которая отправляет ответ в WhatsApp.

Всё работает без сервера и сборщиков: достаточно открыть `index.html`.

### Конверт

Конверт показывается **при каждом открытии и перезагрузке страницы** — так
задумано, никакого «запомнить открытие» нет. По клику:

1. открывается клапан конверта;
2. из конверта поднимается письмо;
3. взлетают красные, синие, жёлтые и белые шарики;
4. падает конфетти;
5. экран плавно уходит, открывается приглашение.

Если у гостя включено «уменьшение движения» в системе, анимации сокращаются.

## Вишлист: как это работает

На сайте есть отдельный блок **«Вишлист Айдарика»** с 9 идеями подарков:

1. Песочница
2. Барабан
3. Робот-карбот
4. Ролики
5. Автопарк
6. Автомат
7. Настольные игры
8. Игрушка «Burger cutting»
9. Фигурка из «Истории игрушек»

Рядом — размеры: **одежда 116, обувь 29**.

В анкете есть необязательный пункт **«Что планируете подарить?»** с теми же
вариантами. Это лучший вариант для такого праздника:

- гости сразу видят идеи и не ломают голову;
- вы получаете в WhatsApp не только «приду / не приду», но и подсказку,
  какие подарки уже выбраны;
- можно мягко избежать повторов;
- при этом подарок не «бронируется» автоматически — гость всегда может
  выбрать что-то своё или оставить сюрприз.

Поле необязательное: если гость не хочет раскрывать подарок, он выбирает
«Пока секрет / выберу сам(а)». Если выбирает «Свой вариант подарка», ниже
появляется поле, где можно написать, что именно он планирует.

## Быстрый старт

1. Откройте `index.html` двойным щелчком — сайт уже работает.
2. Замените рисованные фото на настоящие (см. ниже).
3. Проверьте номер WhatsApp.
4. Загрузите папку на хостинг.

Для проверки на телефоне в той же Wi-Fi сети:

```powershell
python -m http.server 8000
# затем откройте http://localhost:8000
```

### Дата и время

В `config.js`:

```js
eventDate:    '2026-11-21T10:00:00+09:00',
eventEnd:     '2026-11-21T13:00:00+09:00',
birthdayDate: '2026-11-16T00:00:00+09:00',
timezone:     'Asia/Yakutsk',
```

`+09:00` — Якутск. Для Москвы используйте `+03:00`, для Новосибирска `+07:00`.
От этих дат считаются обратный отсчёт, календарь, отметки 16 и 21 ноября и
файл для добавления в календарь.

> После смены даты пройдитесь поиском по `index.html` и поправьте текстовые
> даты: главный экран, блок «Наш герой», календарь, программу, дедлайн,
> подвал и вишлист.

### Место и 2ГИС

Сейчас настроено:

```js
venue: {
  name: 'Kids Story',
  address: 'г. Якутск, ул. Дальняя, 83',
  mapLink: 'https://2gis.ru/yakutsk/firm/70000001081875975'
}
```

Кнопка «Открыть в 2ГИС», карта-заглушка и ссылка в подвале ведут на карточку
Kids Story. Если адрес или место изменится — замените `name`, `address` и
`mapLink`, а также заголовок и текст блока «Штаб праздника» в `index.html`.

### Вишлист

Карточки находятся в секции `#wishlist` в `index.html`. Чтобы добавить или
убрать подарок:

1. отредактируйте карточку `.wish-card` (номер, иконку, название, подпись);
2. добавьте или уберите такой же `<option>` в `select#fGift` в анкете;
3. при необходимости поправьте текст в блоке «Чтобы подарки не повторялись».

Иконки — это SVG-символы в начале `index.html` (`#i-sandbox`, `#i-drum`,
`#i-robot` и т. д.). Можно заменить на свои.

### Фотографии

Сейчас в `assets/img/` лежат рисованные SVG-заглушки. Два способа заменить:

1. **Проще:** положите свои файлы с теми же именами (`portrait.svg`,
   `moment-1.svg`, …). Тогда код менять не нужно.
2. **Удобнее:** положите `jpg/webp` в `assets/img/` и поправьте пути в
   `index.html`.

Рекомендации:

- портрет Айдара — вертикальный, 3:4, от 900×1200;
- фото для галереи — от 1000 px по длинной стороне;
- сжимайте снимки (например, [squoosh.app](https://squoosh.app)), чтобы
  страница быстро открывалась с телефона;
- не забудьте про `alt` и подписи: они видны в лайтбоксе.

Если хотите добавить ещё фото — скопируйте кнопку `.gallery__item` в
`index.html` и положите файл в `assets/img/`.

### Анкета и WhatsApp

Ответы уходят не на сервер, а в WhatsApp:

```js
rsvp: {
  mode: 'whatsapp',
  whatsapp: '79220172467',
  whatsappDisplay: '+7 (922) 017-24-67'
}
```

После отправки открывается чат с уже готовым текстом: имя, ответ, количество
взрослых и детей, пожелания по еде, **планируемый подарок**, пожелание Айдару
и контакт. Гостю остаётся нажать «Отправить». Это самый простой вариант без
регистраций и серверов.

Если номер изменится, поменяйте `whatsapp` в `config.js`, а также видимый
текст номера в `index.html` (поиск по `922 017-24-67`). Ссылки `wa.me` и
`tel:` обновятся из конфига автоматически.

### Соцсети

Превью ссылки — `assets/img/og-cover.png` (1200×630). Его можно перерисовать
в графическом редакторе, сохранив имя файла. Для корректного отображения в
мессенджерах укажите в `og:image` полный адрес сайта, например:

```html
<meta property="og:image" content="https://ваш-сайт.ru/assets/img/og-cover.png">
```

## Календарь

Кнопка «В календарь» скачивает `aidar-5-let.ics` с датой, временем, адресом и
описанием из `config.js`. Файл открывается в Google Календаре, Apple Calendar,
Outlook и на телефонах. Время переводится в UTC автоматически, поэтому гости
из других часовых поясов увидят корректное время.

## Публикация

- **GitHub Pages** — загрузите папку в репозиторий, `Settings → Pages →
  Deploy from branch`.
- **Netlify** — перетащите папку на [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel** — `vercel` из папки проекта или импорт репозитория.
- **Обычный хостинг** — загрузите файлы по FTP в корень сайта.

После публикации проверьте:

- открытие на телефоне (конверт, шарики, прокрутка);
- что ссылка 2ГИС ведёт на Kids Story;
- что ответ из анкеты открывает WhatsApp с текстом и подарком;
- превью ссылки в мессенджере;
- что после обновления страницы снова показывается конверт.

## Структура проекта

```
index.html                 — разметка и все тексты
assets/
  css/style.css            — оформление, адаптив, анимации
  js/config.js             — дата, место, WhatsApp
```

(на Windows это Arial Black / Segoe UI / Segoe Script).

## Если что-то не работает

- **Конверт не открывается** — проверьте, что включён JavaScript. Без него
  страница сразу показывает приглашение (есть `noscript`-стили).
- **Анкета не открывает WhatsApp** — браузер мог заблокировать новое окно.
  На экране «Спасибо» есть кнопка «Открыть WhatsApp ещё раз».
- **Не скачивается файл календаря** — некоторые браузеры блокируют
  автоматические скачивания; попробуйте открыть сайт в Chrome/Safari.
- **На компьютере нет шрифтов Arial Black / Segoe Script** — сайт покажет
  системные заменители, вёрстка не сломается.
